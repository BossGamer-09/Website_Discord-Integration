Import Pilots from CSV

Upload a CSV export from the old project. The following columns are used:

  • name — pilot name (required)
  • team_fighting, duelling, leadership — skill ratings 0–5
  • tags — JSON array e.g. ["legion","comp_team"]
  • notes, notes_updated_at — optional free-text notes

The old id (UUID) and created_at columns are ignored — Django assigns new PKs. org_player is always left blank; it links automatically when the user signs in or the bot sees them. Pilots with an "inactive" tag are imported as inactive.
